# 终末地音乐终端 · 功能按键说明

ENDFIELD Audio Terminal v1.4.1 — 界面与按键操作手册。
本手册按界面分区，逐一说明每个可交互元素的作用。

---

## 一、全局结构

应用采用「顶部状态栏 + 主内容区 + 悬浮 MiniPlayer + 底部 Dock」的固定布局。
除正在播放页为固定布局外，各主界面（含系统配置页）均可上下滚动；左右滑动屏幕可在五个主界面间切换。

### 顶部状态栏（StatusBar）

| 元素 | 作用 |
|---|---|
| 左侧状态圆点 + SYS ONLINE | 系统在线指示，绿色常亮表示终端正常运行（仅显示，不可点） |
| 中央 ENDFIELD OS v2.4 | 系统版本标题，居中显示（仅显示） |
| 右侧日期 / 时间 / 信号柱 | 当前日期、时间与信号强度指示（仅显示） |

### 底部 Dock（BottomNav）

毛玻璃悬浮胶囊，位于系统手势条之上，不贴屏幕边缘。五个入口等宽排列：

| 顺序 | 名称 | 图标 | 作用 |
|---|---|---|---|
| 1 | 介质库 | ListMusic | 进入介质库，查看与管理全部歌曲 |
| 2 | 播放序列 | List | 进入播放序列，管理收藏与自建播放序列 |
| 3 | 搜索 | Search | 进入全域检索，搜索歌曲 / 艺术家 / 播放序列 |
| 4 | 正在播放 | Disc3 | 进入音频输出页，查看当前播放与播放控制 |
| 5 | 设置 | Settings | 进入系统配置，切换背景、主题与终端行为 |

当前所在界面的图标高亮、加粗并显示编号代码，下方出现指示圆点。

## 二、介质库

### 顶部工具

| 按键 | 作用 |
|---|---|
| 扫描设备（Radar 图标） | 扫描手机本地存储中的音频文件并自动加入介质库，读取封面并按同目录同名 .lrc / .txt 读取本地歌词（不联网）；首次使用会请求音频访问权限 |
| 导入曲目（黄色按键） | 打开系统文件选择器，手动选择一个或多个音频文件导入 |

### 扫描状态与统计

| 元素 | 作用 |
|---|---|
| 扫描结果提示条 | 显示扫描结果（新增 / 跳过 / 失败 / 权限被拒），右侧「×」清除提示 |
| TRACKS | 当前（筛选后）歌曲数量 |
| TOTAL | 当前歌曲总时长 |
| READY 绿点 | 终端就绪指示 |

### 介质标签筛选

标签用于给歌曲分类。横向标签行：

- **ALL**：显示全部歌曲。
- **战场记录 / 通讯日志 / BGM / 环境音**：点击仅显示带该标签的歌曲，再次点击取消筛选。

### SYSTEM LOG（系统日志）

- 点击展开 / 收起导入与扫描的过程日志，失败项以红色显示。

### 歌曲行（TrackRow）

每行对应一首歌曲：

| 按键 | 作用 |
|---|---|
| 序号 / 封面 / 标题区域（点击行主体） | 播放该歌曲；正在播放时序号位置显示动态均衡器指示 |
| Tag（标签图标） | 打开「介质标签」面板，为该歌曲勾选 / 取消分类标签 |
| Heart（心形） | 收藏 / 取消收藏该歌曲，收藏后心形填充高亮，并同步到「收藏」播放序列 |
| ListPlus（加入列表图标） | 打开「加入播放序列」面板，将该歌曲加入指定播放序列或新建播放序列 |
| Trash2（垃圾桶） | 从介质库移除该歌曲 |

### 介质标签面板（TagSheet，底部弹出）

- 四个标签按键：勾选 / 取消对应标签，可多选。
- **CLEAR**：清除该歌曲的全部标签。
- 右上角「×」：关闭面板。

### 存储权限弹窗（权限被拒时）

- **取消**：关闭弹窗。
- **前往设置开启**：一键跳转至系统应用详情页，手动开启「音乐和音频」（低版本为「存储」）权限后返回重新扫描。

### 空状态

介质库为空时，可在此页面直接点「扫描设备」「导入曲目」，或将音频文件拖拽到该区域导入。

## 三、播放序列

### 新建播放序列

| 元素 | 作用 |
|---|---|
| 名称输入框 | 输入新建播放序列的名称（最长 32 字），回车提交 |
| ＋ 按键 | 创建播放序列；名称为空时不可点 |

### 播放序列卡片

包含一个系统内置「收藏」播放序列（心形图标，不可删除）与用户自建播放序列：

| 按键 | 作用 |
|---|---|
| 播放序列主体 / 下拉箭头（点击） | 展开 / 收起该播放序列内的歌曲列表 |
| Play（黄色播放键） | 播放整个播放序列，并将该播放序列设为当前播放队列 |
| Trash2（垃圾桶，自建播放序列才有） | 删除该播放序列（不删除歌曲本身） |

### 展开后的歌曲

| 操作 | 作用 |
|---|---|
| 点击歌曲行 | 播放该歌曲 |
| Heart（收藏播放序列内） | 将该歌曲移出收藏 |
| Trash2（自建播放序列内） | 将该歌曲从该播放序列移除（歌曲仍保留在介质库） |

## 四、搜索（全域检索）

| 元素 | 作用 |
|---|---|
| 搜索框 | 主动点击后才弹出键盘；输入关键词实时检索本地介质库与播放序列 |
| 右侧 X（有输入时） | 清空关键词并保持输入框聚焦 |
| 高级检索语法（可展开） | 查看高级搜索用法 |

### 高级检索语法

多个条件以空格分隔，为 AND（同时满足）关系：

| 语法 | 作用 |
|---|---|
| `artist:名称` | 按艺术家筛选 |
| `album:名称` | 按专辑筛选 |
| `tag:标签` | 按介质标签筛选，如 `tag:战场记录` |
| `duration:<秒数` | 筛选时长小于指定秒数的歌曲，如 `duration:<120` |
| 普通关键词 | 匹配歌曲标题 / 艺术家 / 专辑 |

### 搜索结果

- **播放序列结果**：点击播放整个播放序列。
- **歌曲结果**：点击播放键或歌曲行播放该歌曲；右侧 Heart 收藏 / 取消收藏。
- 无结果时显示 NO MATCH。

## 五、正在播放（音频输出页）

本页内容固定在 Dock 上方，整页不滚动、无遮挡。

### 顶部按键

| 按键 | 作用 |
|---|---|
| SPECTRUM | 开启 / 关闭实时频谱可视化，开启后按键高亮 |
| QUEUE | 打开当前播放队列面板 |

### 封面 / 歌词切换

- **ARTWORK**：显示正方形完整专辑封面（封面为纯正方形、完整呈现，不裁剪）。
- **LYRICS**：显示同步歌词。
- 切换时带横向滑动过渡动画。

### 频谱区（开启 SPECTRUM 后显示）

随音乐实时跳动的 24 柱频谱，反映各频段音量。

### 曲目信息（四列等宽）

| 列 | 含义 |
|---|---|
| TRACK | 当前曲目序号 / 总曲目数 |
| 编码列 | 音频编码格式，如 MP3 / FLAC |
| 采样率列 | 采样率，如 44.1kHz |
| 码率列 | 比特率，如 320kbps |

### 标题区

显示当前歌曲标题、艺术家与专辑。

### 进度区

| 元素 | 作用 |
|---|---|
| 进度条 | 点击或拖动到任意位置进行快进 / 快退 |
| 左侧时间 | 当前播放时间（主色显示） |
| 右侧时间 | 歌曲总时长 |

### 播放控制键

| 按键 | 规格 | 作用 |
|---|---|---|
| 模式键 | 44×44 切角边框 | 循环切换三种播放模式（见下） |
| 上一曲 | 44×44 切角边框 | 切换到上一首歌曲 |
| 播放 / 暂停（中央大键） | 56×56 主色高亮 | 播放或暂停当前歌曲 |
| 下一曲 | 44×44 切角边框 | 切换到下一首歌曲 |
| 静音键 | 44×44 切角边框 | 静音 / 取消静音，静音时图标变为 VolumeX |

### 播放模式（三态循环）

| 模式 | 图标 | 含义 |
|---|---|---|
| 序列循环 | Repeat | 按列表顺序播放，播完循环 |
| 无序序列 | Shuffle | 随机顺序播放 |
| 单介质循环 | Repeat1 | 单曲循环播放 |

### 音量区

- 拖动音量滑块调节音量（0–100%），右侧显示当前音量百分比；静音时滑块归零。

## 六、歌词界面

### 无歌词时

| 按键 | 作用 |
|---|---|
| REQUEST REMOTE LYRIC（联网图标） | 主动联网为当前歌曲匹配并下载歌词 |
| IMPORT LOCAL SCRIPT（文件图标） | 从本地选择 `.lrc` / `.txt` 歌词文件导入 |

> 扫描歌曲时不会自动联网匹配歌词，需由用户在此界面主动选择。

### 有歌词时的工具栏

| 元素 | 作用 |
|---|---|
| -1s / -0.5s | 将歌词时间轴整体提前 1 秒 / 0.5 秒 |
| +0.5s / +1s | 将歌词时间轴整体延后 0.5 秒 / 1 秒 |
| SYNC 显示 | 当前时间轴偏移量，设置会持久化保存 |
| SCROLL | 滚动模式：当前演唱行始终居中并高亮 |
| LOG | 日志模式：一次性显示全部歌词，当前行高亮 |

## 七、播放队列（QueuePanel，底部弹出）

| 按键 / 操作 | 作用 |
|---|---|
| 点击半透明背景 | 关闭面板 |
| SAVE SNAPSHOT | 将当前队列保存为一个播放序列快照 |
| CLOSE | 关闭面板 |
| 点击歌曲行 | 播放该歌曲 |
| ListX（行右侧） | 将该歌曲从当前队列移除 |

## 八、设置（系统配置页）

本页可上下滚动，内容始终位于悬浮 MiniPlayer 与 Dock 上方，不会被遮挡。

### 背景 BACKGROUND

| 选项 | 作用 |
|---|---|
| 黑色 BLACK | 应用使用纯黑色外壳（深色模式） |
| 白色 WHITE | 应用使用纯白色外壳（浅色模式），状态栏图标与毛玻璃同步适配 |

### 主题 THEME

| 主题 | 名称 | 作用 |
|---|---|---|
| T-01 | 标准终端 | 默认黄 / 黑 / 白配色 |
| T-02 | 棱镜频谱 | 亮粉 / 青绿 / 明黄多色配色 |
| T-03 | 自定义 | 使用用户自定义配色 |

每张主题卡显示三个等宽色块，点击即应用并覆盖全部界面。

### 自定义配色（常驻显示）

该面板固定显示在主题卡下方；点击色块或切换颜色通道会自动切换到 T-03 自定义主题。

| 元素 | 作用 |
|---|---|
| 恢复默认 | 将自定义配色重置为默认值 |
| 主色 / 辅助色 / 点缀色（三通道） | 选择当前要编辑的颜色通道 |
| 预设色板（12 色块） | 点击色块，将该颜色应用到当前选中的通道 |

### 终端行为 TERMINAL

| 元素 | 作用 |
|---|---|
| 扫描线 ON/OFF | 开启 / 关闭背景的终端扫描线纹理，改动实时生效 |
| 蜂鸣 ON/OFF | 开启 / 关闭界面操作的提示蜂鸣音，改动实时生效 |
| SCAN SPD 滑块 | 调整扫描线滚动速度，范围 4–24 秒 |
| LOG | 循环切换终端日志级别：TRACE / INFO / WARN / ERROR（低于该级别的日志不再显示在 SYSTEM LOG 面板） |
| IDLE（常亮 / 1 分钟 / 5 分钟） | 设置无操作多久后进入待机暗屏，改动实时生效 |

## 九、锁屏与后台控制

应用退到后台或锁屏时，系统媒体通知与锁屏界面提供以下控制（由 MediaSession 提供）：

| 控制 | 作用 |
|---|---|
| 播放 / 暂停 | 控制播放状态 |
| 上一曲 / 下一曲 | 切换歌曲 |
| 快退 / 快进 | 后退 / 前进（约 10–30 秒） |
| 进度条拖动 | 拖动锁屏进度条直接跳转到指定位置 |
| 停止 | 停止播放 |

> 说明：蓝牙耳机、线控耳机的媒体按键同样支持上述操作。

## 十、手势操作

| 手势 | 作用 |
|---|---|
| 左右滑动屏幕 | 在五个主界面间切换 |
| 系统返回（边缘侧滑 / 返回键） | 返回上一界面或退出，支持 Android 预测性返回动画 |
